Game & Systems Design

skill game-design systems-design level-design combat-design economy-design prototyping playtesting featured

Overview

5 years designing game systems — from core combat loops and progression economies to puzzle mechanics and player-driven narratives. Specialize in systems that create emergence and player agency.

Projects Using This Skill

  • Chronicles of Aether — Time Echo system, crafting economy, procedural dungeons
  • Lumina — 80 puzzle difficulty curve, daily challenge generator
  • Game Jam Projects — 15+ prototypes (Ludum Dare, Global Game Jam, GMTK)

Key Competencies

Systems Design

  • Core Loops — Design, balance, and document core gameplay loops
  • Progression Systems — XP, skill trees, gear, battle passes, prestige
  • Economy Design — Sources/sinks, inflation control, player trading
  • Combat Design — Frame data, hitboxes, cancel windows, enemy AI archetypes
  • Puzzle Design — Mechanics-first, teach-through-play, difficulty curves

Level & World Design

  • Level Flow — Pacing, tension/release, landmarking, signposting
  • Procedural Generation — Graph-based, wave function collapse, constraint solving
  • Encounter Design — Enemy compositions, arena layout, difficulty scaling
  • Metroidvania Structure — Ability gating, sequence breaks, backtracking value

Process & Documentation

  • GDDs — Living documents, versioned, cross-linked with technical specs
  • One-Pagers — Feature pitches, mechanic proposals, scope definitions
  • Playtest Plans — Hypothesis-driven, metrics-focused, actionable feedback
  • Design Reviews — Structured critique, decision logging, iteration tracking

Tools

  • Excel/Sheets — Complex formulas, simulation sheets, balance modeling
  • Machinations — System simulation, economy balancing
  • Miro/FigJam — Flow diagrams, user journey maps, affinity mapping
  • Notion/Obsidian — Living design docs, cross-linking, templates

Learning Resources

  • Books: “Game Mechanics” (Adams/Dormans), “Rules of Play” (Salen/Zimmerman), “The Art of Game Design” (Schell)
  • Talks: GDC Vault (Systems Design, Economy Design), GMTK, Mark Brown
  • Practice: Board game design, TTRPG homebrew, game jam constraints

Certifications / Achievements

  • GDC 2023 — Systems Design Summit Speaker (pending)
  • “Best Systems Design” — IndieCade 2022 (Chronicles of Aether prototype)
  • Board Game Design — 2 published expansions (self-published)

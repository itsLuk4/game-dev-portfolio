CI/CD & Developer Tooling

skill tools ci-cd github-actions gitlab-ci jenkins docker editor-tools automation

Overview

Building and maintaining CI/CD pipelines, editor extensions, and automation tools that ship games faster. Focus on zero-touch deployments, fast feedback loops, and eliminating manual busywork.

Projects Using This Skill

  • Chronicles of Aether — GitHub Actions: build → test → deploy to Steam/itch (20 min)
  • Lumina — Multi-platform pipeline: Windows/Linux/macOS/Web/Android/iOS
  • Open Source — Unity CI Template (500+ stars)

Key Competencies

CI/CD Platforms

  • GitHub Actions — Matrix builds, caching, artifacts, environments, OIDC
  • GitLab CI — DAG pipelines, child pipelines, package registry
  • Self-hosted Runners — Mac/Windows/Linux, GPU runners for rendering tests

Game-Specific Pipelines

  • Unity — Headless builds, PlayMode/EditMode tests, Addressables builds, IL2CPP
  • Godot — Export templates, web builds, console (NDA) builds
  • Unreal — UAT, Gauntlet, Perforce integration (basic)

Automation & Tooling

  • Editor Extensions — Unity: Custom inspectors, build processors, asset validators
  • Godot: Editor plugins, import pipelines, scene validators
  • Scripting — Bash, Python, PowerShell for build orchestration
  • Docker — Reproducible build environments, dependency caching

Quality Gates

  • Static Analysis — Roslyn analyzers, cppcheck, Godot GDScript linter
  • Automated Testing — Unit, integration, headless gameplay, visual regression
  • Performance Budgets — Frame time, memory, bundle size, load time thresholds
  • Security — Dependency scanning, secret detection, license compliance

Release Management

  • Steamworks — Depot upload, beta branches, build promotion via API
  • itch.io — Butler pushes, channel management, API automation
  • Mobile — Fastlane, App Store Connect API, TestFlight, Play Console
  • Versioning — SemVer, GitVersion, changelog generation (conventional commits)

Learning Resources

  • GitHub Actions Docs — Workflow syntax, contexts, expressions
  • “Continuous Delivery” (Humble/Farley) — Pipeline patterns
  • Unity/Godot CI Community — Shared workflows, best practices

Certifications / Achievements

  • GitHub Actions — 50+ workflow files authored
  • Reduced build time from 45 min → 12 min (caching, parallelization)
  • Zero-downtime deployments for live mobile title (2 years)

Technical Art & Shaders

skill art technical-art shaders hlsl glsl vfx procedural substance blender pipeline

Overview

Bridge between art and engineering — writing shaders, building VFX, creating artist tools, and optimizing art pipelines. Not a traditional artist, but can implement any visual effect technically.

Projects Using This Skill

  • Chronicles of Aether — Ghost shader, time trail VFX, dissolve transitions
  • Lumina — Light refraction/dispersion shader, prism VFX
  • Tools — Shader Graph Library

Key Competencies

Shader Programming

  • HLSL/GLSL — Vertex, fragment, compute, geometry, tessellation
  • Unity Shader Graph / URP — Custom nodes, render features, SRP Batcher compatible
  • Godot Shader Language — CanvasItem, Spatial, Sky, Particle shaders
  • Techniques — SDFs, raymarching, procedural noise, temporal effects

VFX & Particles

  • Unity VFX Graph — GPU particles, custom attributes, events
  • Godot Particles2D/3D — Curve textures, attractors, collision
  • After Effects → Lottie — UI animations, export pipeline

Procedural Art

  • Texture Generation — Substance Designer, Houdini Engine, compute shaders
  • Mesh Generation — Marching cubes, wave function collapse, spline extrusion
  • Animation — Procedural motion, inverse kinematics, physics-driven

Pipeline & Tools

  • Artist Tools — Custom inspectors, batch processors, validation rules
  • Build Pipeline — Texture compression, atlas packing, LOD generation
  • Color Management — Linear/gamma, ACES, HDR workflow

Learning Resources

  • Books: “Real-Time Rendering” (Akenine-Möller), “ShaderX” series, “GPU Gems”
  • Sites: Shadertoy, The Book of Shaders, Catlike Coding, Ronja’s Tutorials
  • Practice: Weekly shader challenges, Shader Toy weekends

Certifications / Achievements

  • Shader Toy — 3 featured shaders (2022-2024)
  • Unity VFX Graph — Early access tester, bug reporter

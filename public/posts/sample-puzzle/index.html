Lumina

game portfolio project godot puzzle released light-physics minimalist procedural mobile-friendly

Overview

Lumina is a serene puzzle game where players guide beams of light through increasingly complex arrangements of prisms, mirrors, and filters. No text, no tutorials — just pure visual problem solving.

My Role

Solo Developer — Designed, programmed, and produced the entire game:

  • Designed 80+ handcrafted puzzles across 5 chapters
  • Built a procedural puzzle generator for daily challenges
  • Implemented realistic light simulation (refraction, reflection, dispersion)
  • Composed adaptive ambient soundtrack
  • Handled publishing to Steam, itch.io, and web

Key Features

  • Realistic Light Physics — Snell’s law, Fresnel equations, spectral dispersion
  • 80+ Handcrafted Levels — Carefully curated difficulty curve
  • Daily Procedural Puzzles — Infinite replayability with seeded generation
  • Colorblind Modes — 4 simulated color vision deficiency options
  • Zero UI — Pure environmental storytelling
  • Photo Mode — Export beautiful light compositions

Tech Stack

  • Engine: Godot 4.1 (GDScript)
  • Rendering: Custom light simulation shader
  • Audio: Godot AudioServer with adaptive layers
  • Export: Web (WASM), Windows, Linux, macOS, Android
  • Localization: 12 languages via CSV

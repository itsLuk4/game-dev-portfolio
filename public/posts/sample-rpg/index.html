Chronicles of Aether

Overview

Chronicles of Aether is a 2D action RPG where players manipulate time to solve puzzles, defeat enemies, and explore a fractured world. The core mechanic — Time Echoes — lets players record their actions and play them back to create cooperative solo gameplay.

My Role

As Lead Developer & Systems Designer, I:

  • Architected the core time-manipulation system (recording/playback, paradox resolution)
  • Designed the crafting system with 200+ recipes and material properties
  • Built the procedural dungeon generator for replayable endgame content
  • Implemented the save system with timeline branching
  • Led a team of 3 developers through vertical slice to alpha

Key Features

  • Time Echo System — Record 10 seconds of gameplay, spawn a “past self” that repeats actions
  • Paradox Mechanics — Interacting with your echo creates powerful but unstable effects
  • Deep Crafting — Material properties system (conductivity, stability, essence) affects results
  • Branching Narrative — Time choices affect story branches and endings
  • Accessibility — Configurable time dilation, visual indicators, one-handed mode

Tech Stack

  • Engine: Unity 2022.3 LTS (URP)
  • Language: C# (.NET 6)
  • Architecture: ECS (DOTS) for time system, traditional MonoBehaviour for gameplay
  • Tools: Aseprite, FMOD, GitHub Actions CI/CD
  • Testing: PlayMode/EditMode tests, automated regression suite

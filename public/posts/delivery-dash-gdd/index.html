Concept Statement

A fast-paced arcade delivery game where the cargo changes how you drive — pizza goes cold if you’re slow, ice cream melts when you boost — forcing moment-to-moment routing decisions through a living procedural city.

Genre

Arcade / Driving / Roguelite — Core arcade driving (Crazy Taxi lineage) with roguelite run structure (daily challenges, procedural cities, meta-progression).

Target Audience

  • Primary: Players 12–35 who enjoy short-session arcade games (Crazy Taxi, Jet Set Radio, Descenders)
  • Secondary: Speedrun/optimization community (route planning, leaderboards)
  • Platforms: PC (Steam) first, Mobile (iOS/Android) second
  • ESRB: E10+ (Cartoon Violence, Mild Language)

Concept Paragraph & Unique Selling Points

Delivery Dash puts you behind the wheel of a delivery driver racing through a city that never looks the same twice. Your cargo dictates your driving style: pizza demands speed before it goes cold, ice cream punishes boosting (melts faster), fragile packages require smooth driving, hot food rewards aggressive shortcuts.

USPs:

  1. Cargo-Driven Driving — Cargo type dynamically changes optimal driving strategy per delivery
  2. Procedural Cities with Personality — Districts feel distinct (downtown grid vs. suburban curves vs. industrial chaos)
  3. Daily Dash — Seeded daily run with global leaderboard, same city/cargo for everyone
  4. Route Mastery Loop — Plan → Execute → Optimize → Repeat with escalating complexity

Player Experience

Who is the player? A gig-economy delivery driver in a stylized near-future city. Setting: Neon-soaked “Neo Bay City” — 4 districts, day/night cycle, dynamic weather. Session Length: 3–5 minutes per run; 15–20 min for campaign level. Fantasy: “I know this city better than anyone — I am the shortcut.” Emotions: Flow (nailing a perfect drift chain), Tension (ice cream melting, timer ticking), Mastery (shaving seconds off your route), Discovery (finding a new alley shortcut). Phases: Pickup → Route Planning → Execution → Dropoff → Results/Upgrade → Next Run

Key Moments

  1. First 60 Seconds — Tutorial delivers pizza; teaches drift + boost + cargo temperature mechanic
  2. First District Unlock — Suburbs open; longer routes, new cargo types (ice cream, flowers)
  3. First Daily Dash — Seeded run; compares your time against global leaderboard
  4. Campaign Boss Delivery — Timed multi-stop route across all districts; unlocks vehicle
  5. Perfect Run — Zero collisions, all bonuses, top 1% leaderboard — “Driver of the Day” badge

Art, Sound & Music

Visual Style: Stylized low-poly / cel-shaded, saturated neon nights + crisp daytime. Clear readability at speed. References: Jet Set Radio, Sunset Overdrive, Art of Rally. Audio: Synthwave / funk soundtrack (dynamic layers: cruising → drift → boost → near-miss). Engine notes pitch with speed. Cargo-specific audio cues (pizza box rattle, ice cream drip). Key Assets Needed: 15 vehicles, 4 district tile sets, 8 cargo models, UI icons, drift/boost VFX, collision impacts.

Current Target Platform

PC (Windows) via Steam — Keyboard + gamepad. Minimum: GTX 960 / 8GB RAM. Target: 60 FPS @ 1080p. Future: Mobile (Unity URP, touch steering), Steam Deck verified.

Player Objectives and Progression

Who is the Player?

A delivery driver for “Dash Corp” — the city’s fastest (and most reckless) courier service. Silent protagonist; personality expressed through vehicle choice and driving style.

Narrative Synopsis

Neo Bay City’s delivery wars are heating up. Rival corps (SlowMo, SafeRoute) are buying up districts. Dash Corp needs a driver who can prove speed = reliability. You’re that driver. Each district you dominate pushes back the competition.

Primary Goals & Progression

Goal Type Reward
Complete delivery Short-term Cash, XP, cargo bonus
Optimize route (par time) Short-term Efficiency stars, leaderboard
District campaign Medium-term New district, vehicle unlock
Daily Dash top 100 Long-term Seasonal cosmetics, “Courier Rank”
100% campaign Completion “Neo Bay Legend” vehicle + skin

Progression Structure: Linear campaign (20 levels across 4 districts) → Daily Dash (infinite) → Endless Mode (procedural, no timer).

Core Loops

Moment-to-Moment (10–30s): Drift → Boost → Near-miss → Cargo check → Route adjust Run Loop (3–5 min): Pickup → Plan → Drive → Deliver → Results → Upgrade Meta Loop (hours): Campaign → Unlock district/vehicle → Harder runs → Daily Dash mastery

Outer Loop

Earn Cash → Buy Vehicle/Upgrade → Tackle Harder Districts → Better Times → More Cash

Game World

World Fiction

Neo Bay City — a vertical metropolis built on layered highways and modular districts. Corporations own districts; drivers are the lifeblood. The city reconfigures nightly (in-fiction: “The Grid Shift”).

World Organization

District Theme Layout Cargo Specialty Unlock
Downtown Dense grid, verticality Grid + alley shortcuts Pizza, Coffee Start
Suburbia Curved roads, cul-de-sacs Organic, residential Ice Cream, Groceries Lv. 5
Industrial Wide lanes, hazards Factory zones, trains Fragile, Hazmat Lv. 10
Waterfront Docks, bridges, canals Water gaps, cranes Seafood, Live Cargo Lv. 15

MVP Levels: 5 per district (tutorial + 4 campaign). Each adds new cargo type + traffic pattern.

Game World Physics

  • Arcade driving: Drift (handbrake + steer), Boost (meter), Jump (ramps), Powerslide
  • Cargo physics: Temperature (pizza cools, ice cream melts), Fragility (G-force damage), Spillage (liquid slosh)
  • Traffic AI: Personality types (Aggressive, Cautious, Distracted, Erratic) — react to player

Player Movement Through World

Campaign: Linear district progression. Daily Dash: Random district each day. Endless: Infinite procedural stitching.

Easter Eggs

  • “The Shortcut” — hidden alley in each district (time trial unlock)
  • Retro arcade cabinet in Downtown garage (playable mini-game)
  • Dev vehicle: “The Compiler” (unlock via code)

MVP Systems and Features

1. Driving Physics System

Intent: Make driving feel expressive; skill ceiling via drift chaining. Gameplay: Drift builds boost; boost burns cargo temp; near-misses grant bonus. Monetization: None (core gameplay). Technical: Unity DOTS/ECS for vehicle physics; custom tire model (Pacejka-lite).

2. Cargo System

Intent: Cargo = gameplay modifier, not just flavor. Gameplay:

  • Pizza: Temp decays over time; boost accelerates decay
  • Ice Cream: Temp decays; boost rapidly accelerates decay
  • Fragile: G-force threshold; collision = damage
  • Hot Food: Temp rises over time; boost maintains heat Monetization: Cosmetic cargo skins (pizza box art).

3. Procedural City Generation

Intent: Infinite variety, learnable patterns. Gameplay: Wave Function Collapse for district layout → Graph-based road network → Traffic seeding. Monetization: None.

4. Traffic AI

Intent: Living city that reacts to player. Gameplay: 4 personalities × 3 density levels. Yield/block/race behaviors. Monetization: None.

5. Delivery Routing & Scoring

Intent: Reward planning + execution. Gameplay: Multi-stop TSP-lite routing; par times per route; efficiency stars (★★★). Monetization: None.

6. Vehicle Progression

Intent: Meaningful choices, not just stats. Gameplay: 15 vehicles across 5 classes (Compact, Sedan, Coupe, Truck, Special). Upgrades: Engine, Tires, Suspension, Cargo Bay. Each changes handling feel, not just numbers. Monetization: Base vehicles via gameplay; cosmetic skins via DLC.

6. Daily Dash

Intent: Daily habit, community competition. Gameplay: Seeded run (same city, cargo, traffic for all). Global leaderboard. Seasonal cosmetics for top 1%/10%/50%. Monetization: Prestige only.

Technical Documentation

Major Technical Risks

  1. Procedural generation determinism across platforms (PC vs Mobile)
  2. Traffic AI performance at 60 FPS with 50+ vehicles
  3. Drift physics consistency keyboard vs gamepad vs touch
  4. Daily Dash seed sync across timezones/regions

Target Hardware

  • Min: Intel i5-4460 / GTX 960 / 8GB RAM / 10GB SSD
  • Rec: Intel i5-10400 / RTX 2060 / 16GB RAM / 10GB SSD
  • Mobile: Snapdragon 765G / 4GB RAM (iOS A13+)

Infrastructure

  • Directory Structure: /Assets/Scripts/{Core,Gameplay,Systems,UI,Tools} — feature folders
  • Data Format: ScriptableObjects for vehicles/cargo; JSON for procedural seeds; CSV for localization
  • Naming: System_Purpose (e.g., Traffic_Spawner, Cargo_Temperature)

Network Architecture (Future)

  • Daily Dash leaderboards: HTTPS → PlayFab/Steamworks
  • Ghost data: Compressed replay (inputs + seed) ~2KB/run

AI/Procedural Systems

  • City Gen: WFC + Graph grammar → deterministic from seed
  • Traffic: Behavior trees + utility AI
  • Economy: Dynamic pricing based on district demand (future)
